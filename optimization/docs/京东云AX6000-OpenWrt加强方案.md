# 京东云 AX6000（RE-CP-03）OpenWrt 加强方案

> 定位：刷机教程 → 优化配置方案（第一阶段，已完成）之后的**第三阶段进阶方案**。
> 原则不变：一次只加一类功能，加完验证，能回退。每项标注【价值/难度/风险】，
> 按推荐顺序排列，挑需要的做，不必全做。
>
> 前提（均已具备）：公网 IP（动态）、114GB `/data` 数据盘、SQM 已调优、
> iPhone 热点可作备用上行、配置备份在手。

---

## 一、安全加固（建议最先做）【价值★★★ 难度★ 风险低】

1. **更换强密码**：Wi-Fi、SMB、路由器 root 三处（当前 Wi-Fi/SMB 为弱密码）
2. **SSH 密钥登录**：Mac 生成密钥对 → 写入路由器 `authorized_keys` → 可选关闭密码登录
3. **SMB 收紧**：确认仅 lan 监听（已做）；重要目录可单独建只读共享
4. **LuCI 访问控制**：确认仅监听内网（默认即是），公网侧防火墙默认全拒（已是）

## 二、远程访问家里网络（公网 IP 的最大红利）【价值★★★ 难度★★ 风险低】

1. **DDNS 动态域名**：公网 IP 会变，绑一个域名随时找到家
   `apk add ddns-scripts luci-app-ddns`，可用免费服务（如 dynv6、no-ip、阿里云 DNS API）
2. **WireGuard VPN**：手机/笔记本在外安全连回家，访问 SMB、LuCI、家里所有设备
   `apk add luci-proto-wireguard`，MT7986 单线程约 300–500Mbps，日常足够
   搭配 DDNS 使用；只开一个 UDP 端口，暴露面极小
3. **（替代/补充）Tailscale**：不想折腾端口映射就用它，免费、NAT 穿透
   `apk add tailscale`

## 三、双上行自动切换（宽带断网自动走热点）【价值★★★ 难度★★ 风险中】

- **mwan3 故障转移**：宽带（PPPoE）为主、iPhone 热点（wwan）为备，
  宽带断了 30 秒内自动切换，恢复后自动切回
- 前置条件：iPhone 热点开「最大兼容性」（强制 2.4GHz，路由器 sta 才连得上）
- `apk add luci-app-mwan3`，配置两个成员、策略 track_ip 用 223.5.5.5 / 119.29.29.29
- 注意：切换期间公网 IP 会变，WireGuard/DDNS 需 1–2 分钟收敛

## 四、广告过滤与 DNS 优化【价值★★ 难度★★ 风险中】

1. **AdGuard Home**（推荐）：装在 `/data`，全局去广告 + 自定义 DNS + 家长控制
   112GB 空间、861MB 可用内存完全够；接管 dnsmasq 的 53 端口，需要在 LuCI 调整 DNS 走向
2. **DNS 加密（DoH/DoT）**：`https-dns-proxy`，防运营商劫持/投毒
3. **（轻量替代）adblock 插件**：`apk add adblock luci-app-adblock`，只拦域名不带面板

## 五、智能家居隔离（访客/IoT VLAN）【价值★★ 难度★★★ 风险中】

- 新建 `iot` 网段（如 192.168.3.0/24）+ 独立 Wi-Fi SSID（如 COMM_IoT）
- 防火墙：IoT 只能上网，不能访问内网（192.168.1.0/24）和路由器管理口
- 智能音箱、摄像头等全部挪过去，被攻破也摸不到你的电脑和 NAS
- 访客 Wi-Fi 同理（限时、限速、隔离）

## 六、自动化与监控【价值★★ 难度★ 风险低】

1. **配置自动备份**：cron 每周 `sysupgrade -b` 到 `/data/backup/`，保留最近 4 份
2. **磁盘健康周报**：cron 每周记录 `life_time/pre_eol_info` 到日志，异常时告警
3. **LuCI 实时监控图表**：`apk add luci-app-statistics collectd-mod-*`（CPU/温度/流量曲线）
4. **定时任务示例**：凌晨自动重拨/重启（一般不需要，PPPoE 很稳）

## 七、NAS 进阶（114GB 物尽其用）【价值★★ 难度★★ 风险低】

1. **aria2 下载机**：`apk add aria2 luci-app-aria2`，路由器 7×24 挂机下载到 `/data`
2. **miniDLNA 媒体服务器**：电视/手机直接播放 `/data` 里的电影音乐
3. **Time Machine 备份**（Mac 用户）：用 netatalk 把 `/data` 变成 Mac 时光机备份盘
4. **qBittorrent-nox / 阿里云盘 WebDAV** 等按需

## 八、IPv6 应用【价值★ 难度★ 风险低】

- 宽带已下发 IPv6（2408 开头），确认 `wan6` 拿到前缀后内网设备自动获得公网 v6 地址
- 注意防火墙：v6 默认入站全拒（安全），需要远程访问的设备单独放行
- 可配合 DDNS（AAAA 记录）实现免端口映射直连

| 批次 | 内容 | 预计用时 |
